# Projeto Módulo 3 – Low Code/No Code/Vibecode

## 📌 Objetivo do Projeto

O objetivo principal do projeto foi desenvolver uma aplicação funcional explorando os conceitos de Low Code/No Code/Vibe Code para criar um sistema intuitivo, organizado e de rápida implementação.

A proposta escolhida pelo grupo foi criar uma plataforma intuitiva que permitisse aos usuários cadastrar livros, acompanhar o progresso de leitura, receber lembretes e visualizar recomendações de leitura.



---

## 🖥️ Protótipo

O protótipo foi desenvolvido integralmente no Bubble, contendo telas organizadas e componentes visuais voltados para facilitar a navegação do usuário.

Entre as principais funcionalidades implementadas estão:

- Tela de cadastro e login de usuários;
- Área de gerenciamento de informações;
- Sistema de organização de dados em tempo real;
- Interface responsiva e visual intuitivo;
- Fluxos automatizados utilizando os recursos nativos da plataforma.

O funcionamento do sistema ocorre de maneira simples: o usuário realiza o cadastro na plataforma, acessa o sistema por meio do login e consegue visualizar, cadastrar e organizar informações dentro da aplicação. Todas as ações realizadas são processadas automaticamente pelos workflows do Bubble, sem necessidade de programação manual complexa.

Os arquivos de imagens e capturas de tela do protótipo foram armazenados na pasta `/docs`, conforme solicitado na atividade.

---

## ⚙️ Plataforma Utilizada

### Plataforma Escolhida

Bubble

### Justificativa da Escolha

A plataforma Bubble foi escolhida devido à sua proposta de desenvolvimento visual, permitindo a criação de aplicações completas de forma rápida e eficiente. A ferramenta oferece diversos recursos integrados, como banco de dados, autenticação de usuários, automações e criação de interfaces responsivas, tornando o processo de desenvolvimento mais acessível.

Outro fator importante para a escolha foi a possibilidade de validar ideias e construir protótipos funcionais sem a necessidade de conhecimento avançado em linguagens de programação tradicionais. Isso permitiu que o grupo concentrasse esforços na lógica do sistema, organização das funcionalidades e experiência do usuário.

Além disso, o Bubble apresentou uma grande flexibilidade para personalização visual e integração entre componentes, facilitando a implementação das funcionalidades previstas no desafio proposto.

---

## ✅ Vantagens Identificadas

### 1. Desenvolvimento Ágil do Protótipo

Uma das principais vantagens identificadas foi a velocidade no desenvolvimento da aplicação. Utilizando os recursos visuais do Bubble, o grupo conseguiu estruturar telas, fluxos e funcionalidades em um curto período de tempo, reduzindo significativamente o esforço necessário em comparação ao desenvolvimento tradicional.

### 2. Facilidade de Integração entre Funcionalidades

A plataforma oferece integração simplificada entre banco de dados, autenticações, workflows e componentes visuais. Isso possibilitou que diversas funcionalidades fossem implementadas rapidamente, permitindo maior produtividade durante o desenvolvimento do projeto.

### 3. Automação de Processos

Os workflows automáticos do Bubble facilitaram a criação de ações dinâmicas dentro da aplicação, como validação de informações, atualização de dados e navegação entre telas. Essa automação reduziu a complexidade técnica do sistema e contribuiu para um funcionamento mais eficiente.

---

## ⚠️ Limitações Encontradas

### 1. Restrições do Plano Gratuito

Uma das principais limitações encontradas foi relacionada às restrições do plano gratuito do Bubble. Alguns recursos mais avançados da plataforma possuem limitações de uso, desempenho e capacidade de processamento, dificultando a implementação de funcionalidades mais robustas dentro do projeto.

### 2. Dependência da Plataforma

O projeto fica diretamente vinculado ao ecossistema do Bubble, tornando a aplicação dependente da infraestrutura e das regras da própria plataforma. Isso pode gerar dificuldades futuras em casos de migração para outras tecnologias.

### 3. Personalizações Avançadas Limitadas

Embora o Bubble ofereça ampla liberdade visual, algumas personalizações mais específicas exigem conhecimento complementar em HTML, CSS ou JavaScript, o que limita parte da flexibilidade esperada em determinadas funcionalidades.

---

## 📚 Reflexão Crítica

O grupo buscou contornar as limitações da plataforma utilizando soluções criativas e adaptando o escopo do projeto às funcionalidades disponíveis no Bubble. Para lidar com as restrições do plano gratuito, foram priorizadas funcionalidades essenciais, evitando excesso de workflows e componentes desnecessários.

Também foi realizado um planejamento prévio da estrutura da aplicação, permitindo melhor organização dos dados e otimização do desempenho do sistema. Além disso, a equipe explorou recursos nativos da plataforma para substituir implementações complexas que exigiriam programação tradicional.

A experiência permitiu compreender que ferramentas Low Code/No Code são extremamente úteis para prototipagem rápida e validação de ideias, porém ainda apresentam limitações quando comparadas ao desenvolvimento totalmente personalizado.
